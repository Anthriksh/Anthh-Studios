# ANTHH Studio — Final

A cinematic editorial artist portfolio and private Studio CMS for **ANTHH**, the artist pen name.

## Public site
- Artist archive homepage
- About / professional profile
- Music
- Guitars
- Archive
- Media
- Journal / Currently

## Studio
- Edit artist and professional profile
- Manage music, guitars, archive and media
- Publish changes to the public site
- 30-day admin session
- Touch ID / passkey support on compatible browsers

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

The public-facing name throughout the site is **ANTHH**. Internal cookie/storage keys may retain legacy `anthriksh` identifiers for compatibility.
